# Gleis

Gleis is an iOS commuter assistant focused on one core job: notifying users when they should leave home/work/another location to catch their selected train.

## Status

This repository is public for development transparency and collaboration.

## Legal And Data Notes

- Gleis is an independent project and is not affiliated with or endorsed by OeBB.
- Any use of third-party transport data/APIs must comply with provider terms and licensing.
- Before production release, use officially approved API access and written permissions where required.

## Privacy And Security

- Local developer settings and credentials are intentionally excluded from version control.
- Do not commit tokens, session IDs, or private keys.
